A sparkline is a small chart with no axes, labels, or grid. It shows just the shape of the data and is sized to fit next to a number in a table row, a dashboard tile, or a sentence. With a few config settings, any Pioneer Charts line or area chart becomes an Angular sparkline.

In A Table

The most common use: one row per metric, with a sparkline showing the trend and a number showing the current value. Hover over or focus on a point to see its week and value.

The Config

Five settings turn a line chart into a sparkline:

  • Hide both axes. Setting xAxis.hide and yAxis.hide removes the ticks and labels and gives their space back to the chart. An 8px margin stays on each side so a point at the edge isn't cut off.
  • Turn off the grid. Setting yAxis.showGrid: false removes the horizontal lines a line chart draws by default.
  • Remove the dots. Setting pointRadius: 0 shows only the line. The points are still there: hovering over or focusing on one shows its dot and tooltip, and it can still be clicked.
  • Fit the y axis to the data. By default, the y axis runs from 0 to 100. A series in the thousands would be pushed flat against the top, and a series of small fractions would lie flat along the bottom. Set domainMin and domainMax to the series' lowest and highest values so the line uses the full height. If the distance from zero matters, leave domainMin at 0 instead.
  • Adjust the height for the hidden axes. When both axes are hidden, the chart keeps the space their margins used, so it ends up height + 28px tall. For example, height: 12 makes a 40px sparkline.

Turning off enableEffects removes the hover crosshair, which doesn't have much room at this size. Each point still shows its tooltip on hover and focus. You don't need to set a width: the chart fills its container and redraws when the container is resized. In a table, though, put the chart in a fixed-width box instead of relying on the cell's width, because an auto-sized cell gets its width from its content.

Tips

  • Keep it short. Every point is a keyboard stop and a pointer target. A few dozen points are easy to read and navigate at sparkline size, but a few hundred would be hard to tell apart.
  • Show the number next to it. A sparkline shows the shape, not the value. Pair it with the current number, as in the table above, so the row can be read at a glance.
  • Use the same scale to compare. Each sparkline above is scaled to its own range. That makes each trend easy to see, but two lines at the same height don't mean the same values. To compare rows directly, give every sparkline the same domainMin and domainMax.
  • Accessible by default. Screen readers announce each point by its key and value, and the arrow keys move between points, like on any chart (see Accessibility). The row's label and number give the summary.
  • Colors. A single series uses the theme palette's first color. Set colorOverride to choose another, such as green for a metric going up and red for one going down.
