A sparkline is a small chart with no axes, labels or grid — just the shape of the data, sized to sit beside a number in a table row, a dashboard tile or a sentence. In Angular, any Pioneer Charts line or area chart becomes one with a few config settings.

In A Table

The classic use: one row per metric, the sparkline showing the trend and the number beside it showing where it stands now. Hover or focus a point for its week and value.

The Config

Five settings turn a line chart into a sparkline:

  • Hide both axes: setting xAxis.hide and yAxis.hide drops the ticks and labels and hand their margins back to the plot, keeping 8px on each side so a point at the edge isn't cut off.
  • Turn off the grid: setting yAxis.showGrid: false removes the horizontal lines the line chart draws by default.
  • Drop the dots: setting pointRadius: 0 leaves just the line. Each point is still there: hovering or focusing it shows its dot and tooltip, and it can still be clicked.
  • Fit the y domain to the data. The y axis runs from 0 to 100 unless told otherwise, which would flatten a series of thousands against the top or one of fractions along the bottom. Set domainMin and domainMax to the series' own lowest and highest values, so the line uses all of its height. Leave domainMin at 0 instead when the distance from zero matters.
  • Set the height for the hidden axes. With both axes hidden the chart keeps the height their margins took, so it draws height + 28px tall: height: 12 makes a 40px sparkline.

Turning off enableEffects drops the hover crosshair, which has little room to work in at this size; each point still shows its tooltip on hover and focus. The chart's width needs nothing at all: it fills its container and redraws when that resizes — in a table, give it a box of fixed width rather than relying on the cell's, since an auto-sized cell takes its width from its content.

Tips

  • Mind the length. Every point is a stop for the keyboard and a target for the pointer; a few dozen points read and navigate well at sparkline size, where a few hundred would be hard to pick apart.
  • Put the number next to it. A sparkline shows the shape, not the value; pair it with the current figure, as in the table above, so the row can be read at a glance.
  • Compare like with like. Each sparkline above is scaled to its own range, which shows each trend clearly but means two lines of the same height don't have the same values. To compare rows directly, give every sparkline the same domainMin and domainMax.
  • Accessible by default. Each point is named by its key and value for screen readers and can be reached with the arrow keys, like any chart's marks (see Accessibility). The row's label and number give the summary.
  • Colors. A single series takes the theme palette's first color; set colorOverride to pick another, say green for a rising metric and red for a falling one.
