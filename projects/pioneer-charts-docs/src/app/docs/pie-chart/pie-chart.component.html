Pie chart component with beautiful animated transitions.

Donut

Set donut on the config to draw the slices as a ring around an empty center; {{ '{}' }} takes every default. The center can hold a short label and subLabel — typically the total the slices add up to. Slices, hover and sliceClicked work the same as on the pie. The controls below edit the chart's donut live; each field is described in the Configuration table.

@let d = donut();
{{ d.innerRadius ?? 0.6 }} {{ d.label ? '' : 'the total' }}

Markup

API

donut Draw the pie as a donut: slices as a ring around an empty center. Off when omitted; {{ '{}' }} turns it on with the defaults below.
  • innerRadius — radius of the hole as a fraction of the pie's radius, from 0 (a plain pie) to 0.9; values outside that are clamped. Default 0.6.
  • label — large text centered in the hole, e.g. a total. Sized to the hole and shrunk to fit across it; left out if it would have to go below 8px. Not drawn when omitted.
  • subLabel — a smaller line under label, fitted the same way. Not drawn when omitted.
  • labelColor / subLabelColor — any CSS color for the two lines, in place of the theme's $gray-800 and $gray-600. Applied as the --pcac-pie-center-label-color / --pcac-pie-center-sub-label-color custom properties on the chart's .pcac-pie-center group, which a stylesheet can set on an ancestor instead.
