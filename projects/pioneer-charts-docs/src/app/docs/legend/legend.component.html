Legend component for displaying chart legends and binding to click events of individual legend items.

Markup

API

Configuration
Property Description Type Default
heading If provided, will display a Heading for the legend. string null
items Collection of legend items to display, in order. Each is a PcacLegendConfigItem:
  • label — the text shown next to the item's color swatch. Required.
  • checked — whether the item is on. An unchecked item is drawn dimmed. Clicking an item (or pressing Enter / Space on it) flips this. Default true.
  • colorOverride — a hex color for the swatch. Left null, the item gets the theme palette's color for its position, the same one a chart gives its series at that index — so a legend whose items are in series order matches the chart without any override.
 PcacLegendConfigItem[] []

config is a two-way model: when an item is clicked the legend replaces its config with one whose item has checked flipped, and writes it back through [(config)] if you bind that way. With a one-way [config] the change only reaches you through the (itemClicked) event.

Events

Binding Description Payload
(itemClicked)="onItemClicked($event)" Emitted when a legend item is clicked or toggled from the keyboard, with every item's updated state — the clicked one's checked flipped. Typically used to set hide on the matching chart series. PcacLegendConfigItem[]
