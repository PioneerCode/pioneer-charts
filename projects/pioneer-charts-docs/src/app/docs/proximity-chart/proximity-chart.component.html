The proximity chart puts one item in the middle and arranges the others around it. Each item's value sets how close to the center it sits. That value can measure how similar an item is to the center, or how far away it is. The chart answers "what's closest to this?" at a glance. Any item, including the center, can be drawn as an image.

Markup

API

center The item the others are compared to, drawn in the middle. It needs a key (its name) and can have an image. Its value isn't used. closeValue / farValue closeValue is the value that puts an item right next to the center, and farValue puts it on the outer edge. Values in between are spaced proportionally, and values past either end stay at that end. The defaults are 1 and 0, which fit a similarity score from 0 to 1. For a distance, flip them: closeValue: 0, farValue: <largest distance>. rings Values at which to draw a faint dashed guide ring. Each ring is labeled using format. No rings are drawn if this is left out. format How values are shown on the ring labels, in the tooltip, and to screen readers, the same as on an axis. For example, Percentage. showLabels Shows each item's key below it, including the center's. Default false. The names appear in the tooltip either way. Leave it off when the names are long or the ring is crowded. showSpokes Draws a faint line from the center to each item. Default true. startAngle Where the first item sits, in degrees clockwise from 12 o'clock. Default 0. Items are spaced evenly and go clockwise in data order, so list the closest item first to put it at the top. centerSize / itemSize The size, in pixels, of the center's image (or its dot's diameter) and of each item's. The defaults are 64 and 40. The chart works best with a few items up to about a dozen. With more than that, they start to crowd each other around the ring. colorOverride Dot colors for items that don't have an image, used in place of the theme palette. Any CSS color works. The center gets the first color, then the items get the rest in data order. If there are more items than colors, the colors repeat.
