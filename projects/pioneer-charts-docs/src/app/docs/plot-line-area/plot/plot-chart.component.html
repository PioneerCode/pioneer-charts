Point images

pointFanOut Plot chart only. Spread points that share a coordinate (same x position and value) around it instead of drawing them on top of one another, where only the last series' point shows and only it can be hovered. Off when omitted; {{ '{}' }} turns it on with the defaults below. Each group is placed evenly around a ring on the shared coordinate — a pair straight up and down, larger groups clockwise from the top, in series order — and the chart reserves edge space for the spread the same way it does for pointImage. Zoom moves a fanned-out group as one. Every point keeps its true key / value in the tooltip, whose context also lists the others at the coordinate in coincident (see Custom Tooltip).
  • gap — space in pixels between neighbouring points on the ring, measured between their image boxes (or hovered dots). Each group gets the smallest ring at which its members sit this far apart. Default 4.
  • radius — a fixed ring radius in pixels for every group, instead of sizing each by gap. Unset by default.
  • showAnchor — draw a dot on the shared coordinate with a spoke to each fanned-out point, so the true value stays marked. Default true. Styled by the theme's .fan-out-anchor and .fan-out-spoke rules.
