Point images

Set image on a data point to draw it in place of the dot, sized by the config's pointImage box. Points without an image keep their dot.

Zoom

With enableZoomX on, the x axis can be zoomed and panned in place: scroll (or pinch) over the chart to zoom from 1× up to 10× around the cursor, then drag to pan. The view never leaves the original domain, and the lines, points, x axis and vertical grid all follow. enableZoomY does the same for the y axis, with the y axis and horizontal grid following; turn on either or both. This demo has both: two weeks of readings every six hours, two series — crowded at 1×, so zoom in on a day or two, and on the 50–90° band the readings actually occupy within the 40–100° axis.

Zoom works the same on the area and plot charts. Both options are off by default. This demo leaves the hover effects (enableEffects) off so the gesture is the only thing happening.
