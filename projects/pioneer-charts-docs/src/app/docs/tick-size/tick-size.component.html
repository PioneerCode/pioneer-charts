The bar, line, area and plot charts accept xTickSize and yTickSize: the length in pixels of the small tick marks along each axis, set independently. Charts draw no tick marks until one of these is set, so setting a size is also what turns them on for that axis.

Try It

Both charts below share the same two values. Drag the sliders to change them; 0 removes the marks entirely.

{{ xTickSize() }}px {{ yTickSize() }}px

Notice the labels move with the marks (D3 places each label at the tick length plus 3px) and the plot area gives up exactly that much room: the chart shrinks to fit its labels rather than pushing them off the edge.

Markup

Notes

  • Each axis is independent. Set one, the other, or both; an axis without a size draws no marks and its labels stay where they have always been.
  • Color comes from the theme. Marks are stroked with $gray-400 via .pcac-axis-tick-marks .tick line; override that rule (or the variable) to restyle them.
  • The chart makes room. The left margin grows with yTickSize and the bottom margin with xTickSize (by the difference from 6px), so the plot area shrinks to keep the labels inside the chart. A shorter tick hands that room back.
  • Only the per-tick marks change. The two end-caps on the axis line itself keep their default length.
  • Zoom keeps it. On line, area and plot charts the x axis is redrawn as you zoom and pan, and it redraws with the same xTickSize.
  • The pie chart has no axes, so it does not take these options.
