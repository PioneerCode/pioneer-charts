The dot plot places each point along a single value axis. Points with the same value, or that fall in the same binWidth bin, stack into a column. This shows how the values are spread out while keeping every item visible, so each one can still be hovered and clicked. A point can also be drawn as an image instead of a dot. The dot plot uses the same data as the Plot Chart: a list of series, each holding its points. A point's value sets its position on the axis, its key is its name, and its series sets its color. Points without a numeric value are skipped, and so are hidden series and hidden points.

Showing the drawn size

When a column is too tall for the chart's height, every mark shrinks by the same amount until the column fits. This means marks can end up smaller than the size set by pointImage (or dotRadius). To see it in the demo above, set binWidth to 5 and raise pointImage. The markFit output tells you how much the marks shrank: 1 means full size, and anything below 1 means they were scaled down. An image is drawn at maxWidth * fit by maxHeight * fit.

Use markFit to keep a size control accurate. Track two values: the size the user picked and the size the control shows. Build the chart's config from the picked size. That way, the marks grow back toward the picked size when the columns get shorter (with different data or a taller chart, for example), and if the chart can't fit the picked size, the control settles on the size that was actually drawn. markFit only emits when the fit changes, so whenever the user moves the control, set the shown size to the picked size and let the next markFit correct it.

Markup

API

value axis On a dot plot, xAxis is the value axis. Set domainMin and domainMax to fix its range. Without them, the axis covers the data, rounded out to even tick values. format controls how its ticks and the tooltip's value are shown, and every label, sub label, tick, and grid setting works as usual. There is no y axis, because a column's height is a count of marks, not a value. yAxis is ignored. binWidth Groups values into bins of this width, in the axis's units, and stacks each bin at its center. Bins start at xAxis.domainMin, or at 0 if that isn't set. When binWidth isn't set, only equal values stack. dotRadius The radius of each dot, in pixels. Default 6. A hovered dot grows by 2 pixels and fills with its series' color. gap The space between stacked marks, in pixels. Default 2. pointImage The largest size (maxWidth / maxHeight) for points that have an image. The image is drawn in place of the dot, the same as on the plot chart. If the tallest column won't fit in the chart's height, every mark shrinks by the same amount until it does, so nothing gets cut off. markFit reports how much they shrank (see Showing the drawn size). colorOverride Colors to use for the series, in order, in place of the theme palette. Any CSS color works. If there are more series than colors, the colors repeat.
