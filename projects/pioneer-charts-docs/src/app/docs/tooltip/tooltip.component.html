Every chart shows a tooltip when you hover over a data point. By default, it shows the point's key and value. To show your own content instead, put an <ng-template pcacTooltip> inside the chart. It's a regular Angular template with the hovered data passed in, so pipes, control flow, your own components, and styles all work as usual.

Markup

Import PcacTooltipDirective along with the chart component, then put an <ng-template pcacTooltip> inside the chart element. The hovered data point is the template's implicit value (let-point, or any name you like). The rest of the context is picked up by name, as in let-group="parent".

Template Context

With strictTemplates on, the template is type-checked against PcacTooltipContext, so point.value and the other fields are checked as PcacData.

Your Own Data

A PcacData only has a key and a value, but a tooltip often needs more, like the customer who placed an order or the unit a reading was taken in. The context's index and parentIndex give the hovered point's position in data. Charts never reorder data, so if you built it from a collection in the same order, with nothing filtered out, you can use those two indexes to look up the original item:

parentIndex is null when there's no parent level, such as for a pie slice or a chart-wide threshold. For a pie, use items[index] directly. For a threshold, index is its position in thresholds (or in thresholds[parentIndex].data for a per-bar threshold). If your collection doesn't line up with data because you filtered, sorted, or grouped it along the way, look items up by key instead, or keep a map from key to item. Otherwise, the index could quietly point to the wrong row.

Styling

When you provide a template, the library applies none of its own tooltip styling: no background, padding, font, or color. It only positions the template (centered above the cursor) and keeps it from blocking the mouse. Your template controls the entire look.

The tooltip is added to <body> so it can float above everything else, but it still carries your component's style scope. That means component styles like the one above apply to it, without ::ng-deep or global CSS.

Notes

  • Every chart supports it. That includes bar (vertical and horizontal, including thresholds), line, area, plot, pie, donut, dot plot, proximity, and state timeline. Without a template, the chart shows the default key/value tooltip, formatted with the chart's xAxis.format / yAxis.format. Those formats aren't applied to a custom template, which gets the raw PcacData.
  • It updates live. The template is created when a hover starts, updated as the mouse moves, and removed when the hover ends. While it's showing, it takes part in change detection like any other view, so a signal read inside it keeps updating.
  • One template per chart. Only the first pcacTooltip template inside a chart element is used.
  • Points in the same spot. On the line, area, and plot charts, the context's coincident field lists every other point at the same coordinate as the hovered one, so your template can show what else is there. The last demo on the Plot Chart page does this, along with pointFanOut, which spreads those points apart so each one can be hovered.
